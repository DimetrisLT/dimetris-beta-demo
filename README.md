# Dimetris BETA demonstracinė versija

Viešas adresas: https://dimetrislt.github.io/dimetris-beta-demo/

Šioje repozitorijoje laikomas tik sukompiliuotas statinis BETA build. Privatus šaltinio kodas, serverio konfigūracija ir aplinkos kintamieji čia nepublikuojami.

Statinėje demonstracijoje veikia IFC, PDF ir DXF apdorojimas naršyklėje, rankiniai matavimai, kiekių suvestinė, patikros ir vietinis projekto saugojimas.

Prisijungimas, debesų projektai, duomenų bazė ir serverinis sinchronizavimas šiame demonstraciniame leidime neveikia.
